## 📖 About the Project

**Nexora** is a modern e-commerce website developed to practice and demonstrate front-end web development skills.

The project focuses on creating an attractive user interface, organizing products, and providing a smooth browsing experience across different screen sizes.

It is also part of my journey toward becoming a skilled software developer.

---

## ✨ Features

- 🛍️ **Product Listing** — Browse and explore products.
- 🔍 **Product Details** — View individual product information.
- 🔐 **Authentication** — Login and registration interface.
- 🛒 **Checkout Page** — Dedicated checkout interface.
- ❤️ **Wishlist** — Save and manage favourite products.
- 🌙 **Dark Mode** — Switch between light and dark themes.
- 📱 **Responsive Design** — Optimized for different screen sizes.
- ⚡ **Interactive UI** — JavaScript-powered functionality.

## 🚀 Getting Started

Follow these steps to run the project locally.

### 1. Clone the Repository

```bash
git clone https://github.com/surajyadav-07/nexora.git
```

### 2. Open the Project

```bash
cd nexora
```

### 3. Run the Website

Open `index.html` in your browser.

You can also open the project in Visual Studio Code and use the Live Server extension.
